# JAM v0.1.0 — First working release

**Release date:** 28 July 2026 (build) · published 12 October 2026
**Platform:** Windows x64 · local-first · binds to `127.0.0.1` only

First working version of JAM, the local-first Job Application Manager: from a
pasted job description to an auditable, submission-ready PDF package, with an
optional AI analyst that never changes anything without explicit approval.

## Highlights

- **Application Wizard**: paste the JD → AI match analysis and strategy → CV
  recommendations → cover-letter generation → PDF package → mark as applied.
- **AI analyst (optional, OpenAI)**: match score, strengths, gaps, risks and
  strategy as validated structured output, with preview/diff and explicit
  acceptance. Quick / Standard / Deep modes, plus a low-cost Batch API queue.
- **Candidate Profile**: structured, versioned profiles with DOCX import,
  SHA-256 evidence archiving, and multiple local profiles with photos.
- **Document safety**: master and submitted files are immutable. Working
  copies are versioned (`_v01`, `_v02`, …), and cover letters are generated
  only from explicit `{{TOKEN}}` templates.
- **PDF finalization**: LibreOffice (with a Word fallback) builds an
  auditable package with a manifest of hashes, sizes and page counts.
- **Bewerbungsliste**: XLSX preview/update with duplicate prevention and
  formatting preservation.
- **Tracking**: dashboard, searchable application list, status history,
  follow-ups, CSV and Markdown AI-brief export.
- **Import**: read-only scan and import of existing application folders.
- **Strategy language**: EN | DE | RO for the AI strategy discussion.
- **Launcher**: `JAM.exe` starts without a console, reuses a running
  instance, and logs to `%LOCALAPPDATA%\JAM\jam.log`.

The package is **virgin**: it contains no candidate profiles, application
database, generated documents, API keys or personal data. A bundled private
Python runtime means no Python installation is required.

### Install

1. Extract the complete ZIP to a writable local folder.
2. Double-click `JAM.exe`.
3. Open **Candidate Profile** and import a CV or create a profile.
4. Set document masters and cover-letter templates under **Settings → General**.
5. Optional: add an OpenAI API key under **Settings → AI Assistant**. The key
   is stored in Windows Credential Manager. Data sharing is **off** by default.

Verify the download in PowerShell:

```powershell
Get-FileHash .\JAM-Virgin-Windows-x64.zip -Algorithm SHA256
```

## Requirements

- Windows 10/11 x64
- LibreOffice (preferred) or Microsoft Word, for PDF finalization
- OpenAI API key and an internet connection, for AI features only. Tracking
  works fully offline.

## Known limitations

- Only explicit cover-letter tokens are replaced. Arbitrary DOCX editing and
  CV rewriting are intentionally unsupported.
- Cover-letter templates are not bundled in the package. Configure your own
  under **Settings → General**.
- Metadata extraction is conservative. Less structured JDs rely on the AI analyst.
- New Bewerbungsliste rows do not clone every custom row style.
- No permanent-delete feature in this MVP.
- Back up the database and the applications folder before upgrading.
